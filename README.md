The projects are structured in separate folders for clarity:

---

## 🧩 Project 1: Sign Up + Professional Timer

### ⏱ Professional Timer
- Start, Stop, and Reset buttons  
- Displays time in **HH:MM:SS** format  
- Prevents multiple intervals from running simultaneously  
- Automatically resets after 24 hours  

**JavaScript Concepts Used:**  
- `setInterval()` and `clearInterval()`  
- DOM manipulation with `innerHTML`  
- Button state control (enable/disable)  

### 📝 Sign Up Form Validation
Client-side validation for:

- **Name** (Required)  
- **Email** (Regex format)  
- **Username** (3–20 characters)  
- **Password** (4–20 characters)  
- **Confirm Password** (Must match password)  
- **Mobile Number** (11 digits, numbers only)  

**Validation Behavior:**  
- Shows error messages in **red**  
- Shows success checkmarks ✔ in **green**  
- Prevents form submission if validation fails  
- Displays alert when form submission is successful  

**JavaScript Concepts Used:**  
- DOM selection with `getElementById()`  
- Conditional statements  
- Regular expressions (email validation)  
- Form submission control with `return false`  
- Dynamic UI feedback

## 🔐 Project 2: Login Form Validation
